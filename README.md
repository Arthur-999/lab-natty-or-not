💪 Projeto Natty or Not: IA ou Natural?

![Natty or Not] (https://github.com/Arthur-999/lab-natty-or-not/blob/main/Imagem%20hiper-realist.png) 

📒 Descrição

Este projeto explora o universo das IAs Generativas, inspirado na tendência "Natty or Not" do fisiculturismo. A proposta é criar conteúdos que desafiem a percepção humana: será que foi feito por uma IA ou por um ser humano? O objetivo é provocar reflexão sobre o realismo das criações digitais.

🤖 Tecnologias Utilizadas

ChatGPT (Copilot) – geração de texto e roteiro

Midjourney / DALL·E / Leonardo.AI – criação de imagens realistas

Runway / Pictory / Synthesia – geração e edição de vídeo com avatares virtuais

Boomy / Moises – geração de trilha sonora e efeitos sonoros

GitHub – versionamento e hospedagem do projeto

Base10 Trend Map – referência para mapeamento de ferramentas de IA

🧐 Processo de Criação

Pesquisa de tendências com base no mapa da Base10

Roteiro gerado com IA sobre o conceito "Natty or Not"

Imagem hiper-realista de fisiculturista criada com IA

Planejamento de vídeo com avatar virtual narrando o conteúdo

Publicação no GitHub e compartilhamento nas redes sociais

🚀 Resultados

Imagem provocativa que desafia o espectador a identificar se é "natty" ou IA

Roteiro pronto para vídeo ou podcast

Repositório documentado e compartilhado com a comunidade DIO

Divulgação com a hashtag #LabDIONattyOrNot

💭 Reflexão

Criar algo “natty” com IA é um paradoxo fascinante. A linha entre o natural e o sintético está cada vez mais tênue. Este projeto mostra que, com criatividade e boas ferramentas, é possível gerar conteúdos que parecem humanos — ou até melhores.
